# Face Detection

On-device face detection using Google ML Kit. fast, accurate, and works offline.

## Features

- **Faces**: Detect coordinates/frame.
- **Landmarks**: Find eyes, ears, nose, mouth.
- **Contours**: Trace facial feature shapes.
- **Classification**: Detect smiling or eyes open.
